# Illustration style

American Peptide Project · CC BY 4.0

Use flat technical diagrams with solid fills, generous margins, and a consistent
stroke weight. Sample color tokens directly from `app/globals.css`. The source
revision used for this asset family defines paper `#f4efe4`, secondary paper
`#e6decc`, ink `#1a2744`, muted ink `#5a6270`, rule `#d4cbb8`, navy
`#1b3a5f`, deep navy `#101e36`, crimson `#8e2f34`, and brass `#8a6840`.
Use crimson sparingly for corrections and brass for a selected feature.

Keep geometry clear at thumbnail scale. Use solid colors and place all
meaning-bearing labels in HTML or SVG text. The social PNGs are rendered from
the editable SVG card templates for crawlers that require raster images. Use
an exact-size PNG fallback and lossless WebP for browser images. Layouts reserve
space using the 1× intrinsic dimensions. High-density variants double both axes.

## Artwork brief

- Standards hero — four overlapping archival sheets with distinct document,
  source, tier, and citation glyphs.
- Methods hero — a graduated vessel and calibration ruler with unnumbered marks.
- Dataset hero — a ruled table with selected cells and an outward export arrow.
- Method headers — concentration vessel, converging paths into a common
  chamber, two profiles inside a screening window, and a single compartment
  beside a schematic decay curve.
- Schema flow — four named nodes with connecting arrows. Keep the same
  accessible title, description, and labels in both orientations.
- Release marker — a folio tab and precision registration marks. The release
  identifier is page text and the accent is a CSS palette token.
- Errata — a margin bracket marking a correction on an archival sheet.
- Empty state — an unfilled record with guide lines. Icon — stacked sheets
  inset into a navy square. Social cards — a large title and short subtitle
  with their companion motif.

The generator and its editable SVGs are the production sources. The brief and
source revision are recorded in the manifest.
