Project

Open-source home

The repository is https://github.com/utilityincoming/american-peptide-org. Two trees are meant to be reused. The website around them is the reading copy.

Calculators

packages/calculators is dependency-free TypeScript: reconstitution.ts, blend.ts, and pharmacokinetics.ts. They are the same formulas the .com tools run. License: MIT. The written method, including edge cases the types do not express, is under /methods.

node --experimental-strip-types --test packages/calculators/calculators.test.ts

Evidence tier schema

packages/evidence-tier holds JSON Schema draft 2020-12 for a claim. schema-0.1.1.json is the text of record. schema-0.1.0.json is the archived shape without scope. The same files are served at:

  • /standards/evidence-tier/v0.1/schema.json
  • /standards/evidence-tier/0.1.1/schema.json
  • /standards/evidence-tier/0.1.0/schema.json

The schema documents are CC BY 4.0, like the spec prose. Normative rules — when a scope note is required, how windows combine, when supersession is blocked — live in the spec, which a validator will not check for you beyond the required fields.

What is not in this tree

The research agent, vendor trust scores, and the rendered catalog stay in the application repository behind americanpeptide.com. Dataset exports on /data are the part of that catalog this project redistributes.

Research reference. Not medical advice, not a dosing protocol, and not an offer for sale. The tools run on americanpeptide.com.
