Method

Pharmacokinetics

Module: packages/calculators/pharmacokinetics.ts · Half-life inputs: pk-half-lives.json

What it answers

Given one elimination half-life in hours, the helpers answer four teaching questions. What fraction of a single dose remains. How long until repeated dosing is near steady state. How much repeated dosing accumulates. How long until a single dose has effectively cleared.

Formulas

Time t, interval τ, and half-life t½ are hours. Decay uses base 2, which is the same as e^(−ln 2 · t / t½).

fraction remaining          0.5 ^ (t / t½)
time to fraction f          t½ × log2(1 / f)          for f in (0, 1)
time to steady state        time to fraction (1 − 0.97)     default 97%
accumulation ratio          1 / (1 − 0.5 ^ (τ / t½))
peak-to-trough              2 ^ (τ / t½)
clearance time              time to fraction 0.03

A reported range is collapsed with the midpoint (low + high) / 2 before any of the formulas run. The curve is drawn against that single number. The range itself is not a confidence interval.

Worked example

Semaglutide’s stored range is 150–184 hours, midpoint 167. One half-life later, fraction remaining is 0.5 by construction. Time to 97% of steady state is t½ × log2(1 / 0.03), about 5.06 half-lives, and it does not depend on whether the dose is weekly. An interval many half-lives long gives an accumulation ratio indistinguishable from 1.

Assumptions

  • One compartment, first-order elimination, instantaneous input. No absorption delay, no flip-flop kinetics, no two-compartment distribution.
  • The half-life is constant. Saturable clearance, target-mediated disposition, and albumin binding that changes with concentration are outside the model even when they matter for the molecule.
  • Time to steady state is independent of dose and of interval because the approach of the trough (and of the average, in this linear model) follows the same exponential as single-dose decay. The accumulation ratio does depend on the interval.
  • 97% and 3% are conventions (about five half-lives). They are not a biological threshold.
  • Where the table stores null, no curve is drawn. A missing human half-life is not filled with a preclinical number. BPC-157, TB-500, and GHK-Cu are stored that way on purpose.

Edge cases

  • Non-positive half-life or interval returns NaN. A negative elapsed time returns NaN.
  • A target fraction outside (0, 1) returns NaN. The function will not solve “time to more than the dose” or “time to zero,” which this model never reaches.
  • Class-overlap notes on the website are a separate, conservative scan of shared pharmacological labels. They are not an output of these formulas and they are not a clinical interaction database.

Scope note

The half-life row keeps the tier of its source: a figure taken from an FDA label is clinical only for the population and route that label measured, and the arithmetic that follows is computed. A preclinical half-life stays preclinical. “Non-human data. Interspecies scaling of this parameter is unreliable and no human equivalent has been published.” None of these curves is a dosing recommendation.
