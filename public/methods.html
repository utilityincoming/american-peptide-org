Methods

How the calculators work

The interactive tools live on americanpeptide.com. These pages are the written method: the formula, the assumptions, the edge cases, and the scope note that belongs on any number the arithmetic produces.

Every output of these calculators is estimate kind computed and tier reference when the inputs are the reader’s own figures. The canonical scope note is: “Unit arithmetic or a registry lookup from the stated inputs. This is a value, not a dosing recommendation.” Registry-backed inputs, such as a half-life copied from a label, keep the tier of that source. The arithmetic does not promote them.

  • Reconstitution — concentration, U-100 draw, doses per vial, and the reverse solve for diluent volume.
  • Blend — one shared draw across several peptides, limited by the scarcest component.
  • Pharmacokinetics — single-compartment elimination, steady state, accumulation, and clearance time.

Reference implementations: open-source modules. Worked numbers in the tests match the examples on these pages.

Research reference. Not medical advice, not a dosing protocol, and not an offer for sale. The tools run on americanpeptide.com.
